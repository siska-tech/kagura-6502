# 6ch 音源（RTL v1.0 RC）

矩形波 3 ch、ノイズ 1 ch、波形 2 ch を 48 kHz・16 ビットのステレオ PCM にミックスし、HDMI と左右の PWM に出力します。

## 2. レジスタ（CPU の `$D400–$D41F`）

ウェイト 0（PHI2 ストレッチなし）、タイミングは `$D000–$D00F`、`$D300–$D33F` と同じ。`$D420–$D4FF` は書き込みを無視し、読むと `$D400–$D41F` の写し（読み出しの副作用は無い）。

| アドレス | 名前 | R/W | リセット値 | 内容 |
|---|---|---|---|---|
| `$D400–$D402` | P0_STEP | R/W | 0 | pulse 0 の位相増分 24 ビット（下位、中位、上位）。周波数 f = STEP × 48000 / 2^24 Hz（分解能 0.00286 Hz）。440 Hz = 153791（`$02 $58 $BF`） |
| `$D403` | P0_DUTY | R/W | 0 | `phase[23:16] < DUTY` で +127、それ以外 −127。1/8 = 32、1/4 = 64、1/2 = 128。**0 は無音** |
| `$D404` | P0_VOL | R/W | 0 | b7..4 左音量、b3..0 右音量（0〜15。波形 ch の `$D313` と同じ形式） |
| `$D405–$D407` | — | R | 0 | 予約（読むと 0、書き込み無視） |
| `$D408–$D40C` | P1_* | R/W | 0 | pulse 1（同じ形式） |
| `$D410–$D414` | P2_* | R/W | 0 | pulse 2（同じ形式） |
| `$D418` / `$D419` | N_PERIOD | R/W | 0 | ノイズの更新間隔 − 1（16 ビット、下位・上位）。LFSR は PERIOD + 1 サンプルごとに 1 歩進む |
| `$D41A` | N_VOL | R/W | 0 | ノイズの音量（b7..4 左、b3..0 右） |
| `$D41B` | MVOL | R/W | **32** | マスター音量。出力 = clamp((Σ 音声 × 音量) × MVOL / 16)。32 = ×2（6 ch すべて最大でも飽和しない）、128 = 8696e2c の波形 2 ch と同じ音量 |
| `$D41C` | ENABLE | R/W | 0 | b0〜b2 pulse 0〜2、b3 ノイズ。0 の ch は 0 を出力し、位相・LFSR・カウンタを保持する |
| `$D41D` | PRST | R/W | 0 | 位相リセット要求（ビット配置は ENABLE と同じ）。**次の COMMIT が取り込み、0 に戻る**。pulse は位相 0、ノイズは LFSR = 1・COUNT = PERIOD。ENABLE に関係なく働く |
| `$D41E` | STATUS | R | 0 | b0 BUSY（COMMIT の反映待ち）、b1 DROP（HDMI 送信部が受け取る前に次のサンプルで上書きした。**読むと 0**）。他は 0 |
| `$D41F` | COMMIT | W | — | 書くと（値は無関係）`$D400–$D41D` の全体を、次の 48 kHz サンプルから一度に反映する。読むと 0 |

- **`$D400–$D41D` は、書いただけでは音に反映されない。** COMMIT で、全 ch・MVOL・ENABLE・PRST が同じサンプルから一斉に変わる（和音の発音、音程と音量の同時変更で途中の値が鳴らない）。これは AUD-003 の第一候補「設定値の保持は 1 組、COMMIT 書き込みで反映」の実装である。
- 読み出しは書いた値（反映済みかどうかに関係なく）。
- COMMIT 後の反映は、`clk_pix` で 4 クロック以内（54 ns 以内）に写しを取り、次の 48 kHz サンプルから使う。CPU は 1 バスサイクル（3.375 MHz で 296 ns）より速く次の I/O を書けないので、**BUSY を待つ必要は無い**（Sim で、CPU の読み出しで BUSY = 1 を見た回数は 0）。

### 2.1 波形 ch 4〜5（既存、`$D310–$D318`、変更なし）

[VDP レジスタ](vdp.md) のとおり。INC 24 ビット（48 kHz ごとに加算、上位 8 ビットがサンプル番号）、VOL（b7..4 左、b3..0 右）、ACTRL（b0 ch4、b1 ch5）。COMMIT の対象ではなく、書いた次のサンプルから反映される。波形メモリは VRAM `$09A00–$09BFF`（16 ビット単位で書く）。

無効な波形チャンネルはミックスに 0 を加える。

### 2.2 1 サンプルの計算（全 ch 共通の規則）

```text
pulse : out = (STEP==0 || DUTY==0) ? 0 : (phase[23:16] < DUTY ? +127 : -127);  phase += STEP
noise : out = lfsr[14] ? +127 : -127;
        COUNT==0 ? (lfsr = {lfsr[13:0], lfsr[14]^lfsr[13]}, COUNT = PERIOD) : COUNT--
wave  : phase = ACTRL ? phase + INC : 0;  out = ACTRL ? table[phase[23:16]] : 0     (既存の順序)
mix   : acc = Σ out × VOL（4 ビット、L と R 別々）           |acc| ≤ 6 × 128 × 15 = 11520
        L/R = clamp((acc × MVOL) >>> 4, −32768, 32767)        （飽和。折り返さない）
```

- pulse とノイズの規則は kagura-hd `docs/audio-spec.md`（AUD-002 が参照する仕様）と同じ: 現在の位相で値を決めてから位相を進める、DUTY 0 と STEP 0 は無音、無効の ch は状態を保持、LFSR 初期値 1・周期 32767、PERIOD を変えても COUNT は 0 になるまで再ロードしない。
- STEP ≥ `$800000`（24 kHz 以上）は折り返し（エイリアス）になる。kagura-hd はこれを COMMIT で拒否していたが、KAGURA-6502 は AUD-003 に従い kagura-hd の ABI（エラー応答）を持ち込まないので、拒否せずにそのまま鳴らす。
- 波形 ch の規則は既存の実装のまま（位相を進めてから読む、無効で位相 0）。
